# Структура исправленной ЛР2

Проект приведен к структуре, аналогичной примеру `Local_Mage_Mission_Analyzer`:

- `Analysis` — основной анализатор, фабрика анализатора, результат обработки;
- `Builders` — Builder для централизованной сборки миссии;
- `Entities` — доменная модель миссии;
- `Filtering` — точка расширения для будущей фильтрации;
- `GUI` — консольный интерфейс;
- `Logging` — простое логирование обработки;
- `Parsers` — парсеры JSON, XML, TXT, YAML и событийного протокола;
- `Reports` — стратегия формирования отчетов;
- `Validation` — валидация обязательных полей.

Код проверен через `javac` и запуск jar-файла на всех примерах из `src/main/resources/examples`.
